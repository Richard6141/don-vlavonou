📋 ÉTAPES D'INSTALLATION (15-30 minutes)

1️⃣  COPIER SUR VOTRE SERVEUR WEB
   • Si vous avez XAMPP : Copier dans C:\xampp\htdocs\
   • Si vous avez WAMP : Copier dans C:\wamp64\www\
   • Si vous avez un serveur distant : Uploader via FTP

2️⃣  CRÉER LA BASE DE DONNÉES
   • Ouvrir phpMyAdmin : http://localhost/phpmyadmin
   • Créer une base "don_vlavonou"
   • Importer le fichier : config/database.sql

3️⃣  CONFIGURER LE PROJET
   • Copier : config/config.example.php
   • Renommer en : config/config.php
   • Éditer config/config.php et remplir :
     - Identifiants MySQL (DB_USER, DB_PASS)
     - Clés FedaPay (obtenir sur https://fedapay.com)
     - Clés KkiaPay (obtenir sur https://kkiapay.me)
     - Email Gmail + mot de passe d'application

4️⃣  AJOUTER LES IMAGES
   Dans le dossier assets/images/, ajouter :
   • logo.png (Logo Union Progressiste)
   • vlavonou.jpg (Photo de Vlavonou)
   • favicon.png (Icône du site)
   • fedapay-logo.png (optionnel)
   • kkiapay-logo.png (optionnel)

5️⃣  TESTER
   • Ouvrir : http://localhost/don-vlavonou/public/
   • Remplir le formulaire de test
   • Vérifier que tout fonctionne

🔑 OBTENIR VOS CLÉS API

FedaPay (Paiement Mobile Money + Cartes)
  1. Aller sur https://fedapay.com
  2. Créer un compte
  3. Dashboard → API → Copier les clés
  4. Commencer en mode "sandbox" (test)

KkiaPay (Paiement Mobile Money + Cartes)
  1. Aller sur https://kkiapay.me
  2. Créer un compte
  3. Dashboard → API → Copier les clés
  4. Commencer en mode "sandbox" (test)

Gmail (Pour envoyer les reçus)
  1. Aller sur https://myaccount.google.com/apppasswords
  2. Générer un mot de passe d'application
  3. Copier ce mot de passe dans config.php
